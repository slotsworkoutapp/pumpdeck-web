# Hero collage images

Drop screenshots of exercises from Instagram / TikTok / YouTube in here —
the kind of post someone actually saves. They become the drifting collage
behind the hero headline.

- **Format:** `.webp` (preferred), `.jpg`, `.png` or `.avif`
- **Shape:** portrait, roughly 3:4 to 9:16. They're cropped to fill, so keep
  the subject centred.
- **Size:** about 800px wide is plenty — they render around 340px. Compress
  before committing; this is the first thing anyone loads.
- **How many:** the grid is 4 columns x 6 tiles = 24 slots. 24 files means
  every tile is unique, 12 shows each about twice in different columns, and 8
  still looks deliberate. Any number works.
- **Naming:** anything. They're sorted naturally, so `01.webp`, `02.webp` … is
  the easiest way to control the order.

With none in here the collage falls back to tinted tiles, so the layout is
judgeable before any images exist.
